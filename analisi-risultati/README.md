# Analisi dei risultati

Script che calcolano le misure del Capitolo 4 dai file degli esiti delle campagne (`output/tests/batches-*.csv`).

```powershell
python analisi-risultati/numeri_capitolo4.py             # scrive analisi-risultati/numeri-capitolo4.json
python analisi-risultati/analizza_blocco_a.py --revisione   # report di confronto fra le tre applicazioni
```

Si lanciano dalla cartella principale del progetto (con il terminale di `terminale.bat`).
