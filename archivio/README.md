| `documenti-di-lavoro/` | rapporti e note di lavoro scritti durante le campagne e gli scenari di test |
| `registri-di-lavoro/` | registri (`.log` e `.txt`) delle esecuzioni, prodotti dai programmi di controllo |
| `materiale-di-prova/` | file di prova (pagine HTML salvate, configurazioni di prova ridotte) |
