Legenda — tipi di mutazione (operatori a–k)

IDNomeDescrizione
aAttribute Value ModificationChange the VALUE of an existing attribute on an element, keeping the same attribute name.
bAttribute RemovalRemove an existing (non-essential) attribute from an element.
cAttribute Identifier ModificationRename an existing attribute (change the attribute name, keep its value).
dText Content ModificationChange the visible text content of an element.
eText Content RemovalRemove/empty the visible text content of an element.
fHTML Tag Movement (within a container)Reorder an element among its siblings inside the same parent container.
gHTML Tag Movement (any point of the HTML tree)Move an element to a different position elsewhere in the template tree (different parent).
hHTML Tag Movement (between two templates)Move an element out of this template into another component template.
iHTML Tag RemovalRemove an element's tag but keep its text/children (unwrap).
jHTML Tag Type ModificationChange the tag name of an element (e.g. div -> section), keeping attributes and content.
kHTML Tag InsertionInsert a new wrapper/container tag around an existing element (add a hierarchy level).
